# They Left

**They Left** is a 2D top-down survival game developed with **Godot Engine**. Explore a post-apocalyptic world, gather resources, craft essential items, and build machines to survive in a polluted environment.

## Features

- 🌍 Explore a post-apocalyptic world
- 🌱 Gather and collect resources
- 🔨 Craft items and construct buildings
- 🍎 Manage your hunger and thirst
- 🎮 Pixel art survival gameplay

## Controls

| Key | Action |
|------|--------|
| **W A S D** | Move |
| **E** | Interact with buildings and items |
| **Tab** | Open / Close Inventory |
| **Right Mouse Button** | Use the currently highlighted hotbar item |

## Play the Game

There are two ways to play:

### Option 1 – Download the Executable (Recommended)

1. Go to the **Releases** section of this repository.
2. Download the latest release.
3. Extract the downloaded `.zip` file.
4. Run **TheyLeft.exe**.

### Option 2 – Play in Your Browser

Play instantly on itch.io without downloading:

🎮 [https://](https://educatemuhdadam.itch.io/they-left)

## Running the Project

To run the source code:

1. Clone this repository.
2. Open the project in **Godot 4.x**.
3. Press **F5** to run the game.
